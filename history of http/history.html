The Beginning of HTTP

HTTP was created by Tim Berners-Lee and his team. There was an early version of HTTP and has been updating ever since. Early versions include HTTP/2 and 3.

HTTP 1

HTTP 1 was the beginning stages of web communication. It was the foundation of how to even begin computer communication. Definitely a testing stage where a lot of things were being improved.

HTTP 2

HTTP 2 Is a better developed version of HTTP. It handled a lot of the bigger websites without much issue. It was also much more secure than HTTP 1 since it was handling bigger sites and requests.

HTTP 3

HTTP 3 is mostly the same as HTTP 2 but better responsiveness and more up to date protocols. It also ensures faster communication in the web.

What is a Quic?

A Quic is another protocol that allows for faster and secure connection going towards HTTP3. It uses UDP to move data amongst the client and the server.
